INDIAN FOOD IMAGE CLASSIFICATION AND RECOGNITION SYSTEM
1. Introduction
This project focuses on developing an image classification system that can 
automatically identify different Indian food dishes using Machine Learning and Deep Learning.
The system uses images of different food categories to train a Convolutional
Neural Network (CNN) model. The images are collected, organized, verified, labelled, 
and preprocessed before model training.
The trained model predicts the food category when a user uploads an image.
This project combines computer vision, image processing, and deep learning 
to build an intelligent food recognition system.
2. Objective
The main objectives of this project are:
- To collect Indian food images from different categories.
- To organize images into separate food-class folders.
- To verify and label the collected images.
- To preprocess images for machine learning.
- To develop a CNN-based image classification model.
- To evaluate the model using standard performance metrics.
- To predict food categories from new images.
- To develop a simple web application for food recognition.

- Duplicate images are deleted.
- Blurred images are removed.
- Damaged images are removed.
- Incorrect labels are corrected.

 4. Annotation Protocol
Each image is checked carefully before adding it to the dataset.
The label assigned to every image must match the actual food category.
Rules followed:
- One image belongs to the correct food category.
- Incorrect labels are corrected.
- Duplicate images are removed.
- Blurred and unclear images are removed.
- Images with multiple unrelated food items are checked carefully.
- Each category is maintained separately.

10. Model Training
The model is trained using a Convolutional Neural Network (CNN).
PyTorch is used as the deep learning framework.
A ResNet-18 pretrained architecture can be used for transfer learning to improve image classification performance.
Training Environment
IDE: Visual Studio Code
Programming Language: Python 3.x
Deep Learning Model: ResNet-18 (CNN)
Framework: PyTorch
Operating System: Windows 10/11
Python Libraries Used
- PyTorch
- Torchvision
- NumPy
- Pandas
- OpenCV
- Pillow
- Matplotlib
- Scikit-learn
Training Steps
1. Load the prepared food image dataset.
2. Apply image preprocessing.
3. Resize images to 224 × 224 pixels.
4. Normalize the image values.
5. Load the pretrained ResNet-18 model.
6. Replace the final classification layer with 20 output classes.
7. Train the model using the training dataset.
8. Validate the model after each epoch.
9. Save the best-performing model.
11. Model Evaluation
After training, the model is evaluated using the testing dataset.
The following evaluation metrics are used:
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
These metrics help measure how correctly the model identifies different Indian food categories.

13. Web Application
A simple web application is developed using Flask.
The application allows users to upload food images and receive predictions.
Application Steps
1. Open the food recognition website.
2. Upload an image of an Indian food dish.
3. The uploaded image is processed by the application.
4. The trained CNN model predicts the food category.
5. The predicted food name is displayed on the screen.
Technologies Used
Frontend: HTML, CSS, JavaScript
Backend: Flask
Machine Learning: PyTorch
Image Processing: OpenCV and Pillow
